Welcome to Layla

Layla is a 3D website builder powered by AI. You describe what you want in plain words, and Layla generates a fully working 3D website — ready to download or publish live.

What is Layla?

Layla uses AI to turn your ideas into real 3D websites built with HTML, CSS, and Three.js. No coding experience needed. If you can describe it, Layla can build it.

✦   Layla generates clean, downloadable code — not locked into any platform. You own everything.

How it works

1

Write a prompt

Describe your 3D website on the home page. Be as simple or detailed as you like.

2

Layla builds it

Our AI reads your prompt and generates a complete 3D website with animations, layout, and style.

3

Preview & edit

See your site live inside Layla. Tweak colors, shapes, and text with follow-up prompts.

4

Download or publish

Export your site as a folder or push it live to GitHub Pages in one click.

Quick Start

Get your first 3D website live in under 5 minutes.

Step 1 — Write your first prompt

Go to the home page and type what you want in the prompt box. Example:

make me a dark portfolio with floating purple cubes and my name in 3D

Step 2 — Hit Build

Press the Build button or hit Enter. Layla will generate your site and show you a live preview.

Step 3 — Download your site

Click the Download button on the preview. You'll get a folder with three files:

  • index.html — your website
  • style.css — all the styles
  • scene.js — the 3D code
✦   Open index.html in any browser and your 3D site works instantly — no server needed.

Writing Prompts

The better your prompt, the better your site. Here's how to write great ones.

Be descriptive

Instead of "make a portfolio," try:

make a dark portfolio with floating geometric shapes, my name in big white 3D letters, and a purple glow effect

Mention the vibe

Words like minimal, dark, cyberpunk, clean, space, neon, luxury help Layla match the right style.

Include what sections you need

3d landing page with a hero section, about me, projects grid, and contact form

Good prompt examples

  • floating galaxy portfolio with stars and 3D text
  • dark neon product showcase with a spinning logo
  • minimal white site with one floating cube in the center
  • ocean wave homepage with blue animated water
✦   You can always refine your site with follow-up prompts like "make the background darker" or "add more shapes."

Customizing 3D

After your site is generated, you can fine-tune every detail.

Colors

Tell Layla what colors to use in a follow-up prompt:

change the background to black and make the shapes gold

Shapes

Swap out the 3D objects:

replace the cubes with floating diamonds

Animation speed

make the rotation slower and add a gentle floating effect

Camera

zoom out the camera and tilt it slightly downward

Downloading Your Site

Your site is yours. Export it any time as a clean code folder.

What you get

When you download, you get a zip folder containing:

  • index.html — the full page structure
  • style.css — all visual styles
  • scene.js — the Three.js 3D scene
  • assets/ — any images or fonts used

Hosting options

You can host your downloaded site anywhere:

  • GitHub Pages (free)
  • Netlify (drag and drop)
  • Vercel
  • Your own server

Publish to GitHub

Push your 3D site live in one click using GitHub Pages.

Step 1 — Connect GitHub

Click "Sign in" and connect your GitHub account. Layla only needs permission to create repos and push files.

Step 2 — Click Publish

On your preview, hit the Publish button. Layla will:

  • Create a new GitHub repo for your site
  • Push your HTML, CSS, and JS files
  • Enable GitHub Pages automatically

Step 3 — Go live

Your site will be live at:

https://your-username.github.io/your-site-name
✦   GitHub Pages is completely free for public repos.

API Reference

Generate 3D websites programmatically with the Layla API.

Base URL

https://api.layla.build/v1

Generate a site

POST /generate { "prompt": "dark portfolio with floating cubes", "style": "dark", "download": true }

Response

{ "id": "site_abc123", "preview_url": "https://preview.layla.build/site_abc123", "download_url": "https://api.layla.build/v1/download/site_abc123" }
